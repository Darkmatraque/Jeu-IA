# Known limitations
- 0.1.0 is not a production release.
- Browser rendering and actual browser persistence have not yet been tested here.
- Gameplay duration and balance not yet validated; no multi-region campaign.
- Mobile requires scrolling the map; desktop is the target.
- Multiple tabs editing one slot may overwrite progress.
- Save migration for future versions is not yet implemented.
- Audio has a single synthesized effect, not a soundtrack.
- Settings and profile controls are basic; no full avatar editor.
- GitHub Pages activation not confirmed; requires repository settings.

# BLACKOUT COURIER
Real-time arcade extraction roguelite. Replaces ECHO FRONTIER; old commits are preserved. Use WASD/ZQSD/arrows, mouse to aim and fire, Space to dash, F for autofire, Escape to pause. Three districts, three ships, twelve randomized upgrades, permanent unlocks, boss fights, endless continuation and local profiles.

Development 0.2.0, not a verified commercial release. Serve with `python -m http.server 8000` and open localhost:8000; GitHub Pages main/root. `npm test` (Node 22). No external dependencies. See PROGRESS.md.

# Local saves
Keys echo-frontier:v1:{1|2|3}:current and :backup. A complete JSON state includes schema v=1, seed, profile, creation/save timestamps, play time, resources, map, stats, achievements, technology, contracts and weather. Settings stored separately. Save after successful actions, periodically while playing and on page hide. A validated previous current state is copied to backup before writing a new current state. Load tries current, then backup. Import size limit 2 MB; schema and resource validation. Unsupported versions rejected; migration not required yet, future migration must be tested. No cloud sync or account. Local storage can be deleted by browser settings; export manually. Simultaneous tabs are unsupported; use one tab per slot.
